# Расшифровка

Локальное приложение для macOS, которое переводит голосовые записи в текст. Перетаскиваешь файл в окно, и расшифровка начинается сразу. Текст получается разбитым по спикерам и с таймкодами. Его можно поправить прямо в окне и сохранить в PDF, Word или TXT.

Всё работает на твоём маке. Записи и текст никуда не отправляются. Интернет нужен только один раз, чтобы скачать модели.

**Пайплайн:** ffmpeg (любой формат → WAV 16 кГц) → [WhisperX](https://github.com/m-bain/whisperX) с моделью `large-v3` → выравнивание по словам → определение спикеров через [pyannote](https://github.com/pyannote/pyannote-audio).

## Что нужно

| | |
|---|---|
| Система | macOS 12 или новее, Apple Silicon (проверено на M2 Pro) |
| Память | 16 ГБ RAM |
| Диск | около 9 ГБ: ~5,5 ГБ модели и ~3 ГБ Python-окружение |
| Софт | [Homebrew](https://brew.sh), Python 3.11, ffmpeg |
| Аккаунт | бесплатный аккаунт на [Hugging Face](https://huggingface.co), чтобы определять спикеров |

## Установка

### 1. Python и ffmpeg

```bash
brew install python@3.11 ffmpeg
```

### 2. Код и окружение

```bash
git clone https://github.com/<user>/<repo>.git rasshifrovka
cd rasshifrovka

python3.11 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -r requirements.txt -c constraints.txt
```

`constraints.txt` фиксирует точные версии всех зависимостей, на которых приложение проверено. Без него pip поставит свежие версии, и pyannote или whisperx могут с ними не заработать.

### 3. Доступ к модели спикеров

Модель определения спикеров открывается только после того, как ты примешь её условия на Hugging Face. Остальные модели скачиваются без регистрации.

1. Войди на Hugging Face и прими условия на странице [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1).
2. Создай токен с правами **Read** в [настройках токенов](https://huggingface.co/settings/tokens).
3. Сохрани токен одним из способов:

   ```bash
   .venv/bin/hf auth login      # самый простой: токен сохранится в ~/.cache/huggingface
   ```

   или

   ```bash
   cp config.example.json config.json   # и впиши токен в поле "hf_token"
   ```

   или задай переменную окружения `HF_TOKEN`.

Без токена приложение тоже работает, только не делит текст по спикерам: в интерфейсе останется режим «Не делить».

### 4. Модели (по желанию заранее)

При первой расшифровке модели скачиваются сами. Это несколько гигабайт, поэтому первый запуск будет долгим. Можно скачать их заранее:

```bash
.venv/bin/hf download Systran/faster-whisper-large-v3
.venv/bin/hf download jonatasgrosman/wav2vec2-large-xlsr-53-russian
.venv/bin/hf download pyannote/speaker-diarization-community-1
```

| Модель | Зачем | Размер |
|---|---|---|
| [Systran/faster-whisper-large-v3](https://huggingface.co/Systran/faster-whisper-large-v3) | распознавание речи | 2,9 ГБ |
| [jonatasgrosman/wav2vec2-large-xlsr-53-russian](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-russian) | выравнивание по словам для русского | 2,4 ГБ |
| [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) | определение спикеров | 31 МБ |

Модели кешируются в `~/.cache/huggingface/hub`. Для английского и других языков модель выравнивания подбирается и скачивается автоматически при первом использовании.

### 5. Запуск

Собери приложение для Launchpad и Finder:

```bash
./build_app.sh                # создаст ~/Applications/Расшифровка.app
```

Или запусти без сборки:

```bash
.venv/bin/python main.py             # нативное окно
.venv/bin/python main.py --browser   # в браузере
```

`.app` ссылается на эту папку и на `.venv`. Если перенесёшь папку, запусти `./build_app.sh` заново.

## Как пользоваться

1. Выбери язык (RU, EN или «Авто») и число спикеров. Если число известно точно, укажи его: так разметка будет точнее.
2. Перетащи файл в окно или кликни по зоне и выбери его. Подойдёт всё, что читает ffmpeg: m4a, mp3, wav, ogg, opus, flac, а ещё видео.
3. Пока идёт расшифровка, видно прогресс каждого этапа и сколько примерно осталось. Её можно остановить.
4. В готовом тексте спикеров можно переименовать в чипах сверху, а сам текст поправить прямо в окне. Таймкоды включаются и выключаются переключателем.
5. Сохрани результат в PDF, Word или TXT. В файл попадут все правки и новые имена спикеров.

Исходный файл копируется во временную папку. Когда расшифровка закончится или будет отменена, эта папка удаляется вместе со всеми промежуточными данными.

Расшифровка идёт на CPU, поэтому длинные записи обрабатываются долго. Одновременно обрабатывается одна запись.

## Настройки

Создай `config.json` из `config.example.json`. Все поля необязательные.

| Поле | По умолчанию | |
|---|---|---|
| `hf_token` | `""` | токен Hugging Face; лучше использовать `hf auth login` |
| `model_size` | `large-v3` | модель Whisper; `medium` или `small` работают быстрее, но ошибаются чаще |
| `compute_type` | `int8` | точность вычислений на CPU |
| `batch_size` | `8` | меньше значение, меньше расход памяти |
| `threads` | `4` | потоки CPU для распознавания; на M-чипах можно ставить 6–8 |
| `default_language` | `ru` | язык, выбранный при старте |

`config.json` добавлен в `.gitignore`, токен в репозиторий не попадёт.

## Если что-то не работает

Лог лежит в `~/Library/Logs/Расшифровка.log`.

- **«ffmpeg не найден».** Выполни `brew install ffmpeg`.
- **Ошибка 401/403 или «gated repo» на этапе спикеров.** Не приняты условия модели pyannote (шаг 3) или токен не найден.
- **«Процесс неожиданно завершился».** Скорее всего, не хватило памяти. Закрой тяжёлые приложения или уменьши `batch_size`.
- **Первая расшифровка долго висит на «Загрузке моделей».** Модели скачиваются, это нормально.

## Устройство

| Файл | Что делает |
|---|---|
| `main.py` | поднимает локальный сервер и открывает нативное окно (pywebview), диалоги открытия и сохранения |
| `server.py` | API на FastAPI: задачи, прогресс, отмена, экспорт |
| `worker.py` | пайплайн WhisperX в отдельном процессе, чтобы его можно было остановить и чтобы память освобождалась |
| `export.py` | экспорт в TXT, DOCX (python-docx) и PDF (reportlab) |
| `config.py` | настройки и поиск токена |
| `static/` | интерфейс и шрифты Oswald и IBM Plex Mono (OFL), лежат локально |
| `build_app.sh` | собирает `.app` |
